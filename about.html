    Keeping it current

    How this site is updated

    No build step, no database. One file holds everything.

    1 · Open data.js

    Everything lives in assets/js/data.js — club details, the squad, and the fixture list.

    2 · Add the match

    Copy a fixture block, set the date and opponent, and list each goal with its minute and scorer.

    3 · Done

    Scorelines, form, season totals, head-to-head and the scorer table all recalculate on their own.
